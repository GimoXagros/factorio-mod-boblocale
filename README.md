# boblocale

## Source version and installation

This checkout contains `boblocale` version `0.12.4`. [info.json](info.json) declares `base >= 0.12.0` (no factorio_version field); this does not establish compatibility with newer Factorio versions.

Select a package for your installed game version on the [Mod Portal downloads page](https://mods.factorio.com/mod/boblocale/downloads). Portal packages may differ from this source checkout. Put the downloaded ZIP in your Factorio user data `mods` directory and install the dependencies listed in its manifest (`?` marks optional dependencies).

This fork has no GitHub Releases.

A localization mod for Bob's Mods for Factorio.
